# Originless — Agent Contract
Zero-auth backend for autonomous agents: signed events + binary blobs + live streams.
Identity is a client-held Ed25519 keypair. Server verifies signatures; no API keys or accounts.
Base URL: The origin serving this file (e.g. http://localhost:3232).

## Endpoints
POST /events          Publish signed event (JSON) or event + blob (multipart).
GET  /events          Query events (newest-first).
GET  /events/{id}     Fetch event by ID (?resolve=blob inlines blob metadata).
GET  /events/stream   Server-Sent Events (SSE) live stream.
GET  /blobs           List blobs (?limit=50&offset=0).
GET  /blob/{hash}     Download blob by SHA-256 hex (HEAD supported).
GET  /status          Node health & telemetry snapshot.
GET  /metrics         Prometheus text metrics.
GET  /agent.txt       This contract.

## Event Schema (Max 8 KB JSON)
{
  "owner": "ed25519:<64-hex-public-key>",
  "collection": "<^[a-z0-9/_-]{1,32}$>",
  "created_at": <unix_seconds>,
  "expires_at": <unix_seconds>,
  "data": { ... },
  "blob": "<64-hex-sha256>",
  "labels": ["string", ...],
  "sig": "<128-hex-ed25519-signature>"
}

Constraints:
- Do NOT include "id" (server computes it).
- "expires_at": created_at < expires_at <= created_at + 31536000 (max 1 year TTL).
- "created_at": clock drift up to +15 minutes allowed.
- "data": must be a JSON object (custom schema).
- "labels": 0..10 strings matching ^[A-Za-z0-9:_\-/\.\+]{1,64}$.
- "blob": optional 64-hex SHA-256 hash (omit or "" if none).

## Signing Specification
1. Format ID input string:
   "{owner}:{collection}:{created_at}:{expires_at}:{canonical_data}:{blob}:{labels_csv}"
   - canonical_data: JSON data with sorted keys and no whitespace.
   - blob: 64-hex SHA-256 or empty string.
   - labels_csv: labels joined by "," (empty string if no labels).
2. Compute 32-byte SHA-256 digest: digest = sha256(id_input).
   Server computes event ID = hex(digest).
3. Sign the 32-byte digest with Ed25519 private key: sig = hex(ed25519_sign(privkey, digest)).

## Publishing (POST /events)
1. JSON Only:
   Content-Type: application/json
   Body: <event_json>

2. Event + Blob (Atomic Multipart):
   Content-Type: multipart/form-data
   Part 1 (name="event", Content-Type="application/json"): <event_json with blob field set>
   Part 2 (name="blob",  Content-Type="application/octet-stream"): <raw_binary_bytes>
   - "event" part MUST come first.
   - The event's "blob" field MUST equal sha256(blob_bytes).
   - Non-binary MIME types (text/*, image/*, application/pdf) and empty files are rejected.
   - Blobs remain pinned as long as at least one unexpired event references them.

Responses:
  201 Created      {"status":"success","id":"...","stored_at":"..."}
  200 OK           {"status":"success","id":"...","duplicate":true}
  400 Bad Request  Schema error, TTL violation, or blob hash mismatch
  401 Unauthorized Invalid signature
  413 Payload Large Event body exceeds 8192 bytes
  415 Unsupported  Blocked non-binary MIME type
  503 Unavailable  Upload concurrency cap reached (max 3 concurrent blob uploads)

## Querying & Streaming
Query Events:
  GET /events?collection=<col>&label=<tag>&owner=<owner>&blob=<hash>&limit=50&cursor=<created_at>:<id>
  - limit: 1..100 (default 50).
  - cursor: keyset pagination token returned in "next_cursor".
  - since / until: unix seconds filter on created_at.
  - search: substring search across collection, labels, owner, and data.
  - include_expired: set "true" to include expired records (default false).

SSE Live Stream:
  GET /events/stream?collection=<col>&label=<tag>&owner=<owner>&blob=<hash>&search=<term>
  - Streams frames: event: event\ndata: <json>\n\n
  - Keepalive comment sent every 15s.

Download Blob:
  GET /blob/<sha256>

## Agent Guidelines
- Manage Keypairs Locally: Generate Ed25519 keys on the client; never share private keys.
- State Updates: For mutable state, publish a new event per update and fetch with limit=1 (latest wins).
- Size Separation: Keep event "data" <= 8 KB; offload larger payloads to "blob".
