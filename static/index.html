      Deploy & API

      One container, seven routes.

      Everything is exposed on port 3232.

      docker run --rm -p 3232:3232 ghcr.io/besoeasy/originless:latest
      services: originless: image: ghcr.io/besoeasy/originless:latest container_name: originless restart: unless-stopped ports: - "3232:3232"
      Method Route Description
      GET /stats IPFS repo and signed event metrics Open
      GET /healthz Container health status Open
      POST /up Upload a file or folder to local IPFS Multipart
      GET /ipfs/{cid} Download content from the local repository Binary
      POST /events Publish an Ed25519-signed event JSON
      GET /events Query events with pagination and filters Open
      GET /events/stream Live Server-Sent Events stream Stream
      Originless IPFS node GitHub Stats JSON Events JSON Event stream Health
