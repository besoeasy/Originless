      Docker Deployment & Commands

      Deploy Originless as an autonomous, self-contained IPFS microservice container.

      Run Container (Foreground)
      docker run --rm -p 3232:3232 ghcr.io/besoeasy/originless:latest
      Docker Compose Configuration 
      services:
  originless:
    image: ghcr.io/besoeasy/originless:latest
    container_name: originless
    restart: unless-stopped
    ports:
      - "3232:3232"
