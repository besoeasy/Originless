What is this node?

One self-hosted process. The numbers below are live, refreshed every few seconds from /status.

  • [*]
    Signed storage — …
    Every record is an Ed25519-signed event, every file a SHA-256 blob. No accounts, no API keys.
  • [*]
    Live subscribers — …
    Writes broadcast over Server-Sent Events the moment they land. The explorer, canvas and chat above all listen.
  • [*]
    Self-cleaning — …
    A janitor purges expired records and orphan blobs. Nothing outlives its expires_at.
  • [*]
    P2P mesh — …
    Nodes gossip signed records over libp2p; signatures are re-verified on receipt.
  • [*]
    Lean runtime — …
    A single Go binary serving plain HTTP on one port.
  • [*]
    Open traffic — …
    Every endpoint is unauthenticated by design; Prometheus metrics live at /metrics.
  • [*]
    Disk headroom — …
    Writes are admission-checked against a 90% ceiling; the janitor sweeps past 85%.

Six endpoints, all open

There is no login step. Events are trusted because of their signatures, and blobs because of their hashes.

EndpointWhat it does
POST /eventsPublish an Ed25519-signed JSON event with expiry time and optional labels.
GET /eventsList records, filtered by collection, label, search text, or ?blob=<hash>.
GET /events/streamReceive new events live as they arrive in real-time over Server-Sent Events.
POST /eventsPublish a signed event and attach binary bytes in a single atomic multipart request (named blob).
GET /blob/<hash>Download content-addressed binary bytes by SHA-256 hash with immutable caching headers.
GET /statusNode telemetry: uptime, memory vitals, storage usage, P2P swarm status, and janitor stats.
Originless is open source. Run it anywhere you can run a container.github.com/besoeasy/Originless
